# SQ66 XU316 四麦与六通道测试记录

## 测试对象

- 主板：2026-08-30 新版 XU316 核心板。
- 启动 Flash：W25Q16JW，1.8 V。
- 麦克风：四路 PDM 输入，DATA0～DATA3，共享 MIC_CLK。
- 固件：`app_six_channel_beam_raw_20260811.xe`。
- USB 名称：`XU316 4Mic Beam + Raw 6Ch 1`。
- USB VID/PID：`20B1:0335`。

## QSPI 与冷启动

1. 读取到 JEDEC ID `EF 60 15`。
2. 状态寄存器 SR2 为 `0x02`，QE 位已开启。
3. 使用 10 MHz QSPI 时钟完成烧录。
4. 连续三次读取前 64 KiB，与参考镜像逐字节比较均为 0 个错误。
5. 完全断电，拔除 XTAG4，仅连接主板 Type-C 后，USB 音频设备可以正常枚举。

该结果证明新板的 Flash 连接、信号完整性和启动配置在当前样机上可工作。后续仍需补充不同温度、电压条件和长时间运行测试。

## 六通道录音

主机识别为 48 kHz、6 通道输入。固件内部样本为 16-bit；macOS 测试命令将录音保存为 24-bit WAV 容器。通道映射为：

| 通道 | 信号 |
|---|---|
| 1、2 | 相同的四麦固定宽侧波束输出 |
| 3～6 | DATA0～DATA3 原始 PCM |

四路麦克风均能采集到人声，完整录音无削波。测试截图：

- `images/testing/macos-six-channel-enumeration-recording-complete.png`：设备枚举、10 秒录音完成及 `ffprobe` 格式确认。
- `images/testing/macos-six-channel-recording-in-progress.png`：录音过程中的实时输出。

## 方向测试

按“左、右、前、后”四个相对方向进行了人声录音。以同一批文件的能量统计结果为参考：

| 方向 | 相对前向电平 |
|---|---:|
| 前 | 0 dB（基准） |
| 左 | -1.45 dB |
| 右 | -1.43 dB |
| 后 | -2.44 dB |

左右差约 0.02 dB，符合宽侧对称性的预期；后向相对前向约低 2.44 dB。当前差异较小，只能说明固定波束处理链路在运行，不能宣称已经形成稳定的强指向远场拾音效果。

## 测试限制

- 四个方向录音并非在消声环境中完成，房间反射、距离、说话声压和摆位误差都会影响结果。
- 部分方向文件经过应用重采样到 16 kHz，且主机 AGC 可能改变通道或文件间的绝对电平。
- 当前算法为零延时等权 delay-and-sum；没有根据麦克风实际间距和目标角度计算分数延时。
- 未完成 AEC、DoA、VAD、降噪、去混响、温漂、长稳和不同样板间的一致性测试。

后续方向性验证应固定声源、距离和声压，在关闭系统 AGC 的条件下同步录制六通道，并输出频率分段方向图，而不是只比较整段 RMS。
